# Portfolio pack templates

UI, copy, performance, SEO, GEO, calculator, and mobile manifests are separate **templates**, not live
product runs. Copy one to a new disposable experiment repository, adjust only
reversible local paths/origin before baseline, and freeze it. Implement and
pin `REPLACE_WITH_...` JSONL evaluator binaries before running: current
browser adapter supplies browser hard gates but not numeric objective, and
the placeholders intentionally fail rather than fabricate scores. Keep
`docs/BET.md`, prompt, manifest, thresholds, route set, adapter versions, and
environment fingerprint protected after freeze. Run only bounded local
evaluations; no deployment or network authority is granted.

These are internal engineering/copy diagnostics. Traffic, clicks,
impressions, praise, synthetic telemetry, and lab scores never count as
promotion evidence. Original product promotion/kill gates stay unchanged.

SEO and GEO add separate source-grounded templates. Phase 4 local route,
canonical, schema, robots, sitemap, entity, passage, and source-coverage
adapters produce diagnostics and artifacts, not live rankings or AI citations.
External HTTPS citation links must match exact `web.geo.source_urls`; a link
is still unverified content, never synthetic citation evidence. Production
origins/paths are explicit placeholders and probes remain unavailable unless
operator separately grants read-only network permission for that run.

Calculator and mobile packs freeze small mutation roots, original product
gate documents, golden fixtures, literal unit/integration adapter commands,
accessibility gates, and two-candidate budgets. Replace adapter placeholders
with product-specific JSONL binaries that actually run native unit and
integration suites; a placeholder cannot pass. Calculator also uses the local
browser adapter for rendered controls, overflow, and motion. Mobile
accessibility gates require real native test/device evidence, not a web score.
Numeric error and completion time are lab objectives only. Every evaluator
declares `requires_network = false`, and no pack grants network or other
external authority. An evaluator declaring network need without manifest
authority is rejected; process-level network isolation of arbitrary adapter
binaries is **not** guaranteed. Inspect and pin adapters before a run. These
packs never deploy, publish an app, buy a domain, send outreach, change a
payment/legal surface, or move a product promotion or kill gate.
